# Brew Journal — подсказки первого входа

Дата: 2026-08-02. Статус: **реализовано** (BJ-10).
Продолжение `docs/brew-journal-ux.md` §11–12: там перечислено, где человек
спотыкается, здесь — что ему показывают, как это устроено и как добавить своё.

---

## 1. Что это такое

Подсказка — затемнение экрана с вырезом вокруг одной зоны и короткой сухой
строкой рядом. Одна зона, одна мысль, одно предложение. Ни иллюстраций, ни
приветственных экранов, ни тура из семи слайдов.

```
┌─────────────────────────────┐
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│
│░░░░┌───────────────────┐░░░░│   ← вырез: зона видна как есть,
│░░░░│     ЗАВАРИТЬ      │░░░░│      остальной экран затемнён
│░░░░└───────────────────┘░░░░│
│░░░░                     ░░░░│
│░░░░ Заваривание начина- ░░░░│   ← карточка под зоной
│░░░░ ется здесь. Нужна   ░░░░│      (или над, если места нет)
│░░░░ пачка на полке.     ░░░░│
│░░░░                     ░░░░│
│░░░░ 1 / 3      ДАЛЬШЕ   ░░░░│   ← счётчик и кнопка
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│
├─────────────────────────────┤
│      СКРЫТЬ ПОДСКАЗКИ       │   ← выключить совсем, с любого шага
└─────────────────────────────┘
```

**Цепочка** — 1…4 подсказки одного экрана подряд. Дальше не читают.

Управление ровно такое: **тап где угодно** или кнопка **ДАЛЬШЕ** — следующий
шаг; на последнем шаге кнопка называется **ПОНЯТНО**; **СКРЫТЬ ПОДСКАЗКИ** —
выключить их во всём приложении. Вернуть — строкой в НАСТРОЙКАХ.

## 2. Правила показа

1. **Первый фактический вход на экран**, а не первый запуск приложения. Человек,
   который дошёл до колеса вкусов на третий день, увидит подсказку колеса на
   третий день — тогда, когда она нужна. На главном экране цепочка идёт сразу
   при первом запуске: пустая полка сама по себе непонятна.
2. **После загрузки данных.** Первая попытка — через 450 мс, дальше опрос раз в
   700 мс, пока на экране не найдётся хотя бы одна зона.
3. **Зона не найдена — шаг пропускается и остаётся непоказанным.** На этом
   держатся условные подсказки: карточка «оценка ждёт» появляется после первой
   заварки, кнопка «+ имя» на колесе — после захода в категорию, диапазон
   помола — после «ВЗЯТЬ В ЗАВАРИВАНИЕ», кнопка «ГОЛОСОМ» — только там, где есть
   распознавание речи. Каждая дождётся своего случая и покажется тогда.
4. **Тап где угодно — следующий шаг.** Тап не проваливается в подсвеченную
   кнопку: человек читал, а не целился.
5. **Показанное пишется по шагам.** Свернул приложение на середине цепочки —
   прочитанное осталось прочитанным. Цепочка при этом фиксируется на старте,
   поэтому счётчик «2 / 3» не пересчитывается под пальцем.
6. **Таймер без подсказок.** Там идёт заваривание, и затемнение экрана стоило бы
   человеку секунд. Проверено тестом, а не намерением.
7. **Карточка не наезжает на нижнюю полосу.** Ставится под зоной, если под ней
   есть место, иначе над; у зоны во весь экран (кольцо колеса) — прижимается к
   верху. Правило чистое и покрыто тестами.
8. Тёмная и светлая темы; RU и EN; тач-таргеты ≥48dp.

## 3. Где хранится «уже показано»

В таблице `settings`, двумя ключами. **Миграции схемы не потребовалось**:
`settings` — key/value, новый ключ это новое поле интерфейса, версия Dexie
осталась первой.

```ts
// db/schema.ts → SettingsValues
hints: string[];    // id показанных подсказок
hintsOn: boolean;   // выключатель, по умолчанию true
```

| Вопрос | Ответ |
|---|---|
| Переживёт перезапуск? | да — IndexedDB |
| Переживёт обновление приложения? | да, старая база просто не имеет ключа и получает дефолт |
| Уедет в экспорт? | да, `collectExport` пишет `settings` целиком |
| Ломает ли формат обмена? | нет, `EXPORT_VERSION` прежний, лишний ключ старый читатель игнорирует |
| Импорт архива без ключа? | подсказки покажутся заново, один раз — принято решением |

**Почему не `localStorage`.** Зеркало в `localStorage` есть у темы, но по
конкретной причине: тему надо знать до первого кадра, иначе экран мигнёт.
Подсказка появляется через полсекунды после отрисовки — асинхронного чтения
IndexedDB хватает с запасом, а второе хранилище без нужды это второй источник
правды.

**Реестр id — append-only**, ровно как id дескрипторов колеса: в базе лежат
строки, и переименование id вернёт подсказку всем, кто её уже закрыл. Удалять
можно, переименовывать — нет.

### Управление в НАСТРОЙКАХ

Две строки рядом с языком и темой:

- **ПОДСКАЗКИ** · `по одной при первом входе на экран` — чипы ВКЛ / ВЫКЛ;
- **ПОКАЗАТЬ ЗАНОВО** ↻ — забыть показанное и включить обратно.

Второе нужнее, чем кажется: проскочивший подсказку тапом иначе не может её
вернуть.

## 5. Из чего это собрано

| Файл | Что |
|---|---|
| `data/hints.ts` | реестр: id, экран, ключ строки, селектор зоны |
| `data/strings.ts` | 36 текстов + 8 подписей интерфейса, RU и EN |
| `db/schema.ts` | ключи `hints`, `hintsOn` в `SettingsValues` |
| `db/repo/settings.ts` | `markHint`, `resetHints`, `setHintsOn`, `useShownHints`, `useHintsOn` |
| `ui/hints/hint-view.ts` | чистая логика: очередь, вырез, сторона карточки |
| `ui/hints/HintLayer.tsx` | поиск зоны, замер, отрисовка; смонтирован в `App.tsx` |
| `ui/hints/hints.css` | затемнение тенью выреза, карточка, нижняя полоса |
| `tests/unit/hint-view.test.ts` | 15 проверок правил §2 и §7 |

**Зона ищется селектором, а не ref'ом.** Половина зон уже помечена `data-testid`
ради e2e; заводить второй механизм разметки ради подсветки не за чем, а `ref`
пришлось бы прокидывать через компоненты, которые о подсказках знать не должны.
Там, где готового `data-testid` не было, экран несёт `data-hint="…"`.

**Опрос, а не `MutationObserver`.** Дешёвый `querySelector` по двум-трём
селекторам раз в 700 мс стоит меньше наблюдателя за всем деревом и не
срабатывает на каждый тик таймера.

### Добавить свою подсказку

1. Строка в `data/strings.ts` — обе таблицы, RU и EN, плюс счётчик ключей в
   `tests/unit/strings.test.ts` (он там намеренно жёсткий).
2. Запись в `HINTS` с новым id и селектором зоны.
3. Если готового якоря нет — `data-hint="…"` на нужный элемент экрана.

## 6. Что проверено на живой сборке

Полный проход в Chromium 393×852 против собранного приложения:

- первый запуск — цепочка главного из трёх шагов, вырез охватывает кнопку;
- тап по подложке и кнопка ДАЛЬШЕ ведут одинаково;
- перезагрузка не возвращает показанное;
- полка → добавление пачки → сетап → **таймер без подсказок** → «оценка позже» →
  диагностика → колесо: на каждом экране своя цепочка;
- заход в категорию колеса поднимает подсказку про «+ имя» — ту самую, что была
  пропущена на корне;
- СКРЫТЬ ПОДСКАЗКИ гасит их везде, ПОКАЗАТЬ ЗАНОВО возвращает;
- тёмная и светлая темы, RU и EN.

`npm run verify` зелёный целиком: датасет, типы, 548 юнит-тестов, сборка
расширения, 18 e2e.

## 7. Решения, принятые по ходу

| Вопрос | Решение |
|---|---|
| Первый запуск | цепочка главного показывается сразу |
| Таймер | подсказок нет вовсе |
| Возраст обжарки | в подсказках не объясняем |
| Импорт архива без `hints` | подсказки покажутся заново, один раз |
| Закрытие | глобальное, с любого шага, возврат — из настроек |

Английские тексты — рабочий вариант, носителем не вычитаны.
