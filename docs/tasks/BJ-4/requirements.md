# Требования — BJ-4: экраны основного цикла

## Контекст
После BJ-3. Спека §5, §7; research: `_research/component-report.md` — это ЕДИНСТВЕННЫЙ источник поведения экранов (каждая группа читает свои секции), эталон вида — `design_handoff_brew_journal 3/Brew Journal offline.html`. Токены — из BJ-2 tokens.css, доменная логика — из BJ-3, конвертер — @coffee/core через domain/convert.

## В скоупе (16 экранов, кроме wheel — он BJ-5)
Общие компоненты: ScreenHeader (микро-лейбл + ←), Stepper (42–56px, ±, зажимы), InverseButton, Tag (рамка 1px, капс), Row/HairlineList, EmptyState.

**Группа G1 — полка**: shelf (карточки: квадратное фото 118px слева, имя/данные, свежесть `N дн · фаза` + остаток `г`/`шт` для дрипа); bean (фото столбцом, первое — лицо, открытие фуллскрин в 1 тап — README:70, D-3 спеки; поля только участвующие в расчётах; список заварок пачки; ЗАВАРИТЬ); beanAdd (СНЯТЬ ПАЧКУ / ВПИСАТЬ РУКАМИ равноправны; форма ЗЕРНО/МОЛОТЫЙ/ДРИП — у дрипа штуки вместо веса; возврат в brew с выбранной пачкой, если пришли оттуда). Фото через platform-интерфейс: web-фолбэк file input + canvas-downscale (WebP q0.85, длинная сторона 2048, thumb 256) — prototype-shell-report §4; Capacitor-камера подключится в BJ-6.

**Группа G2 — заваривание**: brew (сетап: выбор пачки с тегом формы, «+ ЗЕРНО» инлайн; девайсы мини-чертежами + «+ ДЕВАЙС»; гибрид → ИММЕРСИЯ/ПРОЛИВ/СЕРЕДИНА + клапан-степпер; поля по форме кофе — component-report §10.11 таблица шагов/зажимов дословно; помол: текстовый ввод с запятой + степпер ±0.1 + подсказка диапазона из конвертера; ratio 1:N в шапке; СТАРТ и ЗАПИСАТЬ БЕЗ ТАЙМЕРА); timer (elapsed 74px tabular, сегменты шкалы с заливкой, стадия 29px капс, накопительная вода `N г из M`, отклонение ±M:SS, ПАУЗА над главной кнопкой 88px, подписи кнопки по §4.5; тик — rAF/250ms через zustand, БЕЗ прямых DOM-записей прототипа); rateLater (ОЦЕНИТЬ СЕЙЧАС / ПОЗЖЕ).

**Группа G3 — оценка и журнал**: diag (4 шкалы 0–10 тапом по 11 ячейкам; карточка-вход в колесо с цветным мини-колесом 64px — единственное цветное пятно, arcPath из BJ-3; заметка + кнопка ГОЛОСОМ через platform-интерфейс speech с деградацией до клавиатуры без баннеров; предложенные дескрипторы тегами; выбранные теги с интенсивностью ●●○ тап-циклом и ×; поле «что за кофе» для дегустаций); log (фильтры-чипы: all + пачки + режимы + ЧАШКИ; СРАВНИТЬ чекбокс-режим slice(-2)); detail (сетка параметров, стадии с водой и длительностями включая паузы, диагностика строкой, теги, заметка, QR-плейсхолдер до BJ-6, ПОВТОРИТЬ → brew с параметрами); compare (15 строк §9 дословно, отличия белые+700, совпадения #6E6E68; НЕ падать на cup-записях — bean может быть null, D-3 спеки).

**Группа G5 — конвертер**: conv (ОТКУДА — пикер с поиском по 134 кофемолкам ядра, паттерн поведения из пикера расширения: поиск по подстроке, схлопнутые бренды; счётчик базы в шапке; степпер значения с шагом по scale; КУДА — свои молки перебором по тапу; главный результат — диапазон 46px/300 `lo—hi` + полоса-шкала с центром; техстрока `клики · µm · µm/шаг`; ОТКАЛИБРОВАТЬ — панель с подсказкой из журнала (лучшая по сладости), степпер ±0.1, применить/сбросить; ВЗЯТЬ В ЗАВАРИВАНИЕ → brew с центром; component-report §6.2 + domain/convert из BJ-3).

**Группа G4 — девайсы и настройки**: devices (список с мини-чертежами); device (конструктор: 6 групп чипов TRAITS, живой чертёж devSvg — полный порт геометрии §7.1-7.7 включая толщины стенок ПО README (керамика 5.5 > металл > стекло > пластик 0 — D-2 этой задачи), техподпись + заметка о влиянии; сохранение с автовыбором в brew при возврате); more (МОИ КОФЕМОЛКИ CRUD: добавить имя+шаг µm, удалить с «УДАЛИТЬ? ДА/✕», минимум одна; МОИ ДЕВАЙСЫ; ЯЗЫК RU/EN; ЭКСПОРТ/ИМПОРТ-плейсхолдеры до BJ-6; подвал `локально · офлайн · без аккаунта · v0.1`); spec (статичная страница токенов).

## Критерии приёмки
- AC-1: typecheck + vitest journal зелёные; build зелёный; корневой verify не сломан.
- AC-2: полный цикл в браузере (fake-данные): добавить пачку руками → сетап → таймер с паузой → rateLater → diag → done-запись в журнале → деталь → сравнение двух → настройки CRUD молок. Проверяется Playwright-смоуком (новый apps/journal e2e, минимум 1 сценарий цикла).
- AC-3: списание остатка пачки при сохранении заварки (г/шт, зажим нулём).
- AC-4: пиксельная близость: скриншоты home/conv/shelf/brew/timer/diag/log против offline.html — ревью-пасс с изображениями, отклонения либо чинятся, либо фиксируются в review_notes.
- AC-5: тон копирайта — плоские глаголы, строки только из data/strings.ts (никаких хардкодов в JSX).
