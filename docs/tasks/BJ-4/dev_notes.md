## Что сшито

1. **Пачка → сетап.** `BeanAdd` при сохранении смотрит `previousScreen()`
   (новый хелпер в `app/nav.ts`): пришли с `brew` — зовёт
   `useBrewSetup.setBean(id)` и только потом `back()`. Без этого автовыбор сетапа
   встал бы на *первую* пачку, а новая ложится последней (контракт из отчёта G2,
   п. 5).
2. **Девайс → сетап.** `Device` при сохранении делает то же самое через
   `useBrewSetup.setDevice(id)` (`saveDev`, `DC:1280`).
3. **Мини-чертёж в сетапе.** Маркер `INTEGRATION` в `Brew.tsx` заменён на
   `<DevSvg device={d} />`; рамка-плейсхолдер убрана, размер 58×37 — родной
   размер мелкого чертежа.
4. **«ПОВТОРИТЬ».** Уже сделано G3 напрямую через `useBrewSetup.fromEntry`.
   Своего слоя не заводили.
5. **Конвертер → сетап.** Уже сделано G5 через `fromConverter(span)` — уезжает
   весь диапазон, не только центр.
6. **rateLater → диагностика.** Работает подхватом `usePendingEntry()`, как и
   рассчитывал G2. Домашний экран, в отличие от него, зовёт
   `useRate.startRating(id)` / `startTasting()` **явно**: у `startRating` есть
   второй смысл — сбросить набор прошлой сессии, а «ОЦЕНИТЬ ЧАШКУ» без
   `startTasting` открыла бы оценку ждущего заваривания (контракт из отчёта G3,
   п. 3 — там прямо сказано, что `Home` это доделает).
7. **Диагностика → дом.** `saveRating()` + `setTab('home')` — уже было у G3.
8. **`data-screen` на всех экранах.** Экраны G3 (`diag`/`log`/`detail`/`compare`)
   рисовались без этого атрибута, остальные — с ним. Выровнено: приложение стало
   единообразно инспектируемым, и смоук ходит по одному признаку.

`apps/journal/playwright.config.ts` + `tests/e2e/cycle.spec.ts`.

Сценарий 1 — весь цикл: демо-сид → пачка руками → сетап с выбором этой пачки →
СТАРТ → стадии с одной ПАУЗОЙ → ГОТОВО → ОЦЕНИТЬ СЕЙЧАС → шкалы и заметка →

сравнение двух → настройки: добавить и удалить кофемолку.

`verify` не включён** — как и было велено.

Два места в смоуке потребовали объяснения в коде:
- клики по таймеру форсированные: он перерисовывается 4 раза в секунду, и
  проверка «элемент неподвижен» на работающем секундомере не сходится никогда;
- счётчики (пачки, кофемолки) снимаются только после ответа живого запроса
  Dexie, иначе «стало на одну больше» сходится с пустого экрана.
