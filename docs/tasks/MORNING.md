# Утренний отчёт — ночь 02→03.08.2026

## TL;DR
Рабочий прототип готов и в вебе, и как APK. Полный цикл (пачка → заварка с таймером и паузой → оценка со шкалами и колесом → журнал → сравнение → экспорт/импорт) работает офлайн и покрыт e2e. APK собран и запущен на эмуляторе — скриншот `docs/tasks/BJ-7/emulator-home.png`.

## Запустить
- **Веб**: `npm install && npm run -w @coffee/journal dev` → `http://localhost:5173/?seed=demo` (сид демо-данных как в прототипе; без параметра — чистый первый запуск).
- **APK**: готовый `apps/journal/android/app/build/outputs/apk/debug/app-debug.apk` (6.6 МБ) — `adb install`; либо на устройство: `cd apps/journal && npx cap run android`. Gradle требует `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"`.
- **Тесты**: `npm run -w @coffee/journal test` (473), `npm run test:e2e:journal` (6), корневой `npm run verify` (расширение не тронуто, 18 e2e).
- **Ручная проверка на устройстве**: `docs/tasks/BJ-7/qa_checklist_ru.md` — 7 проверок (авиарежим-цикл с камерой, восстановление из экспорта, keep-awake, уведомление, QR, голос, язык).
