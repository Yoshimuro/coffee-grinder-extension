# Контракты — BJ-9

Существующие контракты не менялись. Задача добавила один внутренний:

- **Зеркало темы.** Ключ `bj-theme` в `localStorage`, значения `dark` | `light` |
  `system`. Пишут: `setTheme()` и восстанавливающий эффект `useThemeAttribute`.
  Читает: инлайн-скрипт в `index.html`. Источник правды — не зеркало, а строка
  `theme` в таблице `settings`; зеркало существует ради одного кадра до ответа
  базы и обязано ей следовать.

- **Мост в оболочку.** Плагин `ShellTheme`, метод `apply({ pref, color })`.
  `pref` — выбор пользователя (включая `system`), `color` — уже разрешённый
  цвет фона. Подменять одно другим нельзя: night mode системе сообщается
  выбором, фон красится цветом.

Формат экспорта (`export-zip-v1`) не менялся: `theme` — обычный ключ настроек,
а читатель импорта по замыслу терпит отсутствующие ключи (`transfer.ts`).
