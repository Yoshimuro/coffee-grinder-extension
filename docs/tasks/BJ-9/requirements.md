# Требования — BJ-9: светлая тема

## Контекст

До BJ-9 приложение было dark-only, и это было записано в трёх местах кода как
решение, а не как недоделка: `tokens.css` («Dark is the only theme»),
`index.html` («Dark-only: the light system theme must never be substituted») и
шапка `More.tsx` («ни аккаунтов, ни синхронизации, ни тем»). В §1 спеки то же
стоит среди жёстких рамок.

Пользователь решил это изменить. Прежние формулировки отменяются в части темы;
всё остальное из того списка («ни аккаунтов, ни синхронизации») в силе.

Отдельное требование, поставленное пользователем явно: **тёмный кадр при
холодном старте у светлого пользователя недопустим**. Первая версия плана
относила его к неустранимым — это оказалось неверно, см. `decisions.md` D-4.

## В скоупе

- Три режима: `dark` | `light` | `system`, умолчание `dark` (обновившаяся
  установка обязана выглядеть как вчера).
- Светлая палитра для всех 15 цветовых токенов.
- Настройка в key/value-таблице Dexie + строка в `More.tsx` по образцу языка.
- Отсутствие мигания при загрузке: и в браузере/PWA, и в APK.
- Нативная оболочка Android: статус-бар, панель навигации, фон WebView,
  стартовое окно и splash.
- TODO для будущего iOS-таргета — в коде, а не в голове.
- Скрипт снимков обеих тем (дыра между node-юнитами без рендера и e2e без
  проверки вида).

## Вне скоупа

- iOS-реализация (таргета ещё нет; закладываемся комментариями, не пишем).
- Пересмотр контраста `--faint` (2.7:1 — ниже AA в обеих темах; это решение
  тёмной темы, и менять его надо сразу для обеих, отдельной задачей).
- Тема цветового колеса: рампа oklch остаётся общей, см. `decisions.md` D-3.
- Иконка лаунчера и PWA-иконки: остаются тёмными намеренно.

## Критерии приёмки

- AC-1: выбор темы переживает перезапуск и доезжает до документа.
- AC-2: у светлого пользователя нет тёмного кадра ни при перезагрузке страницы
  (проверяется на `domcontentloaded`, а не на `load`), ни при холодном старте
  APK на Android 12+.
- AC-3: тёмная тема не изменилась — ни одного нового цвета, значения хендоффа
  нетронуты.
- AC-4: `npm run typecheck`, `npm test`, `npm run build:journal`,
  `npm run test:e2e:journal` — зелёные.
- AC-5: в `apps/journal/src` не осталось цветовых литералов, кроме тех, у
  которых есть письменная причина ими быть (QR).
