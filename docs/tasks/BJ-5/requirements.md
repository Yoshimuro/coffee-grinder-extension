# Требования — BJ-5: колесо вкусов (signature)

## Контекст
После BJ-3 (wheel-данные, цвета, arcPath) и BJ-4 (экран diag с входом-карточкой). Research: `_research/component-report.md` §8 — исчерпывающая спецификация реализации; README handoff §6 (юридические рамки: словарь свой, SCA-геометрия/палитра не воспроизводятся).

## В скоупе
Экран `wheel` (React + SVG, порт §8 дословно, если ниже не сказано иное):
- Геометрия: cx=cy=175, r0=74, r1=170, зазор 0.016 рад, старт с 12 часов; viewBox 0 0 350 350, рендер 322px.
- 3 уровня из `data/wheel.ts` (path: [] → категории 9; [cat] → подкатегории; [cat,sub] → дескрипторы-листья). Светлота: категории i%2 ? 0.72 : 0.66; уровни глубже — формулы §8.1. Цвет `oklch(l c h)` — hue/chroma категории.
- Подписи: середина кольца, поворот по сектору, доворот 180° в левой половине, кегль 8/9/10 по числу секторов, текст #0D0D0B, капс, pointer-events none.
- Центральная кнопка (r0−9): «ВСЁ» на корне / «↑ + имя уровня» глубже; тап = вверх.
- Анимация «приближения»: смена key контейнера + CSS whzin (.72→1) / whzout (1.36→1), 320ms cubic-bezier(.22,.8,.24,1), направление по dir ±1.
- Тап по сектору: не-лист → path.push (dir 1); лист → togglePick. Только тап, никаких свайпов.
- Крошки `ВСЁ / Фруктовое / Ягоды` с jump на любой уровень (dir −1); кнопка «+ <имя>» — добавить нелистовой id как дескриптор (canAddHere §8.6).
- Память: белая точка r=2.3 на r1−9 у секторов, где есть ранее выбиравшиеся дескрипторы (union desc всех done-записей из Dexie; для нелистовых — «внутри есть хоть один», через DESC.cat/sub) — без счётчиков.
- Выбранные — теги внизу с интенсивностью (Tag из BJ-4, цикл по D-4 BJ-4), несколько допустимо; ГОТОВО в шапке → назад в diag с выбранным.
- Обводка выбранного листа #FFFFFF 2.5, остальных #0C0C0C 1.5.

## Вне скоупа
Мини-колесо диагностики (сделано в BJ-4), голос-подсказки (BJ-4/BJ-6).

## Критерии приёмки
- AC-1: typecheck+тесты зелёные (юнит: wheelItems по уровням — счётчики/светлота; memHit-логика на фикстурах записей).
- AC-2: e2e-смоук: diag → колесо → категория → подкатегория → лист → тег с интенсивностью появился внизу и в diag; «+ Фруктовое» с уровня категории работает; крошки возвращают.
- AC-3: точки памяти появляются после первой done-записи с дескрипторами.
- AC-4: скриншот-сверка колеса (корень + уровень 2) с offline.html.
- AC-5: корневой verify зелёный.
