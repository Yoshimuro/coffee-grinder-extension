### QA-1 — Установка и запуск
**Предусловия.** Телефон с Android, USB-отладка включена; либо эмулятор `Medium_Phone` из Android Studio.
**Шаги.** `npx cap run android` из `apps/journal` (или `adb install <путь к apk из MORNING.md>`), открыть приложение.
**Ожидаемо.** Домашний экран (вариант C): ЗАВАРИТЬ + ⇄, ОЦЕНИТЬ ЧАШКУ, пустой журнал приглашает заварить. Тёмная тема, статус-бар не наезжает на контент, снизу контент не обрезан home-индикатором.
**Факт.** _(пусто)_

### QA-2 — Авиарежим: полный цикл (главный тест DoD)
**Предусловия.** QA-1 пройден. **Включить авиарежим до старта и не выключать до конца.**
**Шаги.** 1) Полка → СНЯТЬ ПАЧКУ → сфотографировать реальную пачку (лицо + шов с датой) → заполнить форму (зерно, дата обжарки, вес) → сохранить. 2) ЗАВАРИТЬ → выбрать пачку → выбрать/создать девайс → выставить помол/дозу/воду/температуру → СТАРТ. 3) Пройти таймер, **минимум одна ПАУЗА** посреди пролива. 4) ГОТОВО → ПОЗЖЕ. 5) С домашнего — карточка «оценка ждёт» → ОЦЕНИТЬ: 4 шкалы, заметка, колесо (провалиться до дескриптора, интенсивность тапом), сохранить. 6) Журнал → запись видна с оценкой «С N» → деталь: стадии с фактическими длительностями включая паузу. 7) СРАВНИТЬ: выбрать эту и любую другую запись → отличия белым/жирным. 8) Настройки → ЭКСПОРТ БАЗЫ В ФАЙЛ → файл сохраняется/шарится.
**Ожидаемо.** Ни одного сетевого сообщения об ошибке; все шаги проходят офлайн; фото пачки видно на полке и в карточке; остаток пачки уменьшился на дозу.
**Факт.** _(пусто)_

### QA-3 — Восстановление из экспорта
**Предусловия.** QA-2 пройден, экспортный zip сохранён вне приложения.
**Шаги.** Удалить приложение → поставить заново → Настройки → ИМПОРТ → выбрать zip.
**Ожидаемо.** Вся база восстановлена: полка с фото, журнал с записями, свои кофемолки, девайсы, калибровка.
**Факт.** _(пусто)_

### QA-4 — Keep-awake и уведомление
**Шаги.** 1) Запустить заварку, положить телефон, не трогать 3+ минуты. 2) Завершить, выбрать ПОЗЖЕ, свернуть приложение, подождать ~15 минут.
**Ожидаемо.** 1) Экран таймера не гаснет. 2) Приходит локальное уведомление «оценка ждёт»; тап открывает приложение с карточкой оценки.
**Факт.** _(пусто)_

### QA-5 — QR-рецепт
**Шаги.** Открыть деталь любой записи с рецептом → отсканировать QR вторым телефоном.
**Ожидаемо.** Читается компактный JSON рецепта (режим, помол, доза, вода, температура; без личных id).
**Факт.** _(пусто)_

### QA-6 — Голосовая заметка
**Шаги.** На экране оценки нажать ГОЛОСОМ (если кнопка есть), продиктовать заметку с парой словарных слов («черника», «мёд»).
**Ожидаемо.** Текст в заметке; распознанные дескрипторы предложены тегами (не проставлены молча). Если офлайн-распознавание недоступно — кнопки просто нет, никаких баннеров.
**Факт.** _(пусто)_
